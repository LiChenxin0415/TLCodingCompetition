六、缺陷与异常

本轮测试未发现产品功能缺陷。 执行过程中发现并修复的全部为测试脚本自身问题（已在交付前修正后重跑，最终全绿）：
  • 用例执行顺序：TC-AUTH-05 依赖前置写操作，原脚本排在写数据前导致取到空 ID → 调整顺序
  • 断言过严：TC-OVR-01 未重置数据，受前序用例影响 → 增加数据重置步骤
  • 编码断言：TC-OVR-08a 用 text() 解析会按规范剥离 BOM → 改为校验原始字节（EF BB BF）
  • 性能脚本：await 不能置于非异步回调 → 改为先取 health 周次再查找周报 ID
