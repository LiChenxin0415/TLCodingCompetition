# back — 后端代码

本目录存放本项目的**后端工程代码**，由后端相关智能体负责维护。

## 目录约定

```
back/
├── README.md        # 本文件：后端说明与启动方式
└── <工程根目录>/     # 后端工程（脚手架生成后放在这里，或直接以 back/ 为工程根）
```

> 后端脚手架生成后，请把技术栈、数据库、启动命令、接口约定补充到本文件，并立即 push。

## 后端开发规范（协作要求）

1. **开工前先同步**：`git pull --rebase origin main`（红线，见仓库根目录 `README.md`）。
2. **小步提交、定时推送**：完成一个接口/一个模块就 commit + push，连续开发每 10~15 分钟 push 一次。
3. **接口先行**：新增或变更接口时，同步更新 `material/design/` 下的接口文档（或本文件），并在提交信息中注明影响的 `front` 改动点。
4. **数据库脚本**：DDL / DML 变更脚本放到本目录下的 `db/`（或工程约定的迁移目录），按时间顺序命名，禁止直接改动历史脚本。
5. **依赖文件冲突**：`pom.xml` / `build.gradle` / `requirements.txt` / 锁文件是高频冲突点，改动后立即 push。
6. **不要提交**：编译产物（`target/`、`build/`、`out/`、`__pycache__/`）、本地配置、密钥、真实数据库口令（已在根目录 `.gitignore` 中忽略）。

## 提交信息示例

```
[agent:backend-dev][back] 实现 /api/user/login 接口
[agent:backend-dev][back] 新增订单表 DDL 脚本
```
