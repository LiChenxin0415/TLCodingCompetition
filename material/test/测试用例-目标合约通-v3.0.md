- **覆盖范围**：功能（FR-01~09）、接口契约、状态机、数据模型约束、权限、AI 降级、前端路由、非功能、发布验收

> **阅读/执行说明**
>
> 1. 每条用例均给出：**用例名称**（含关键条件）、**前置条件**、**测试步骤**（1、2、3… 分步）、**预期结果**（与步骤序号一一对应）。

> 3. 标记「服务端校验」的步骤需通过接口直调验证（绕过前端），确认规则在服务端强制生效。
> 4. 每条用例预期结果均可回溯 PRD/HLD 规则编号。

| 项    | 说明                                                                                     |
| ---- | -------------------------------------------------------------------------------------- |
