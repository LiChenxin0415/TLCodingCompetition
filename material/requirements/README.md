## 需求要点速览（供快速索引）

- **角色**：member（成员）/ leader（负责人），单团队模型。
- **核心流程**：成员输入→AI 生成→编辑→保存/提交；负责人查看/代编辑→团队总览→AI 汇总。
- **优先级**：P0（登录/模板/AI生成+降级/个人周报/负责人管理）、P1（团队总览+AI团队周报）、P2（导出/自定义模板/提醒/历史查询）。
- **规则 ID 体系**：AUTH（权限）、LOGIN（登录）、TPL（模板）、GEN（AI生成）、REP（个人周报）、LEAD（负责人）、OVR（团队总览）。
