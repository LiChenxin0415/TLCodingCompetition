## 一、设计令牌（Design Tokens）

| 类别 | Token | 取值 | 说明 |
| --- | --- | --- | --- |
| 主色 | `--brand` | `#2F54EB`（蓝紫） | 产品名、主按钮、激活态 |
| 辅助色 | `--success` | `#52C41A` | 已提交状态 |
| 警示色 | `--warning` | `#FAAD14` | ⚠ 风险标签 |
| 危险色 | `--error` | `#FF4D4F` | 删除/越权提示 |
| 文本主色 | `--text` | `rgba(0,0,0,0.88)` | 正文 |
| 文本次色 | `--text-secondary` | `rgba(0,0,0,0.45)` | 占位、说明、灰字占位行 |
| 边框 | `--border` | `#F0F0F0` | 卡片/输入框描边 |
| 背景 | `--bg-layout` | `#F5F7FA` | 页面底色 |
| 圆角 | `--radius` | `8px` | 卡片/按钮 |
| 间距基准 | `--space` | `8px` 栅格 | antd 默认 |

> 直接复用 antd 5 默认主题即可，主色通过 `ConfigProvider` 的 `theme.token.colorPrimary` 覆写为 `#2F54EB`。

## 二、组件 ↔ antd 映射

| 页面元素 | antd 组件 | 备注 |
| --- | --- | --- |
| 顶部导航栏 | `Layout.Header` + `Space` + `Tag` | 产品名 + 用户（姓名+角色 `Tag`）+「切换账号」`Button` |
| 预置账号卡片 | `Card` + `Avatar` + `Tag` | 选中态加 `border`/主色描边（LOGIN-01） |
| 周次标题 | `Typography.Title` | 纯展示 |
| 输入区多行文本 | `Input.TextArea` | `maxLength=2000` + `showCount` 计数（GEN-02） |
| AI 生成按钮 | `Button` + `Loading` | 空输入 `disabled`（GEN-01）；加载态文案（GEN-04） |
| 四字段编辑区 | 4 × `Input.TextArea` | 逐字段独立编辑（GEN-08） |
| 周报列表 / 总览列表 | `Table` | 列定义见需求 4.4 / 4.6.1 |
| 风险 ⚠ 标签 | `Tag color="warning"` | OVR-01 |
| 提交状态筛选 | `Segmented` / `Select` | OVR-02 |
| 空态 | `Empty` + 引导文案 | 禁止白屏（OVR-03 / 第七章） |
| 确认弹窗 | `Modal.confirm` | 覆盖确认（GEN-05）、离开未保存（第七章） |

| 复制 / 导出 | `Button` + `Clipboard` / `Blob` | OVR-08 |

## 三、三态视觉规范（空 / 加载 / 错误）

| 状态 | 触发场景 | 视觉规范 |
| --- | --- | --- |
| **空态** | 我的周报无数据、总览全员未提交（OVR-03） | 居中 `Empty` 组件 + 引导文案（如"还没有周报，点击上方按钮开始第一篇"），**不渲染空表格** |
| **加载态** | AI 生成中（GEN-04）、列表/总览请求中 | 按钮 `Loading` + 禁用编辑区；列表用 `Skeleton` 或 `Spin`；文案"AI 正在整理你的周报…" |
| **错误态** | 401/403/400/504/500（见 api-spec 第九节） | `message.error` 顶部提示；403→"无权限访问"；504→"生成失败，请重试"+降级入口；不显示原始报错（6.3） |

## 四、页面级视觉要点（补充需求第五章）

- **P1 登录页**：4 张账号卡片网格排列，点击高亮；产品名 + slogan 居顶。无空态/错误态（预置账号必然可选）。
- **P2 周报编辑页**：上下分区清晰——①输入区（含计数）→ AI 生成按钮 → ②四字段编辑区 → 操作栏（保存草稿/提交）。降级模式隐藏 AI 按钮，仅留编辑区。
- **P3 我的周报**：顶部「去写本周周报」主按钮；列表行 hover 可点；空态引导。
- **P4 成员管理**：按成员 `Card` 分组，组内 `Table` 按周次倒序；"本周未开始"灰字占位行（无 `Table` 时不渲染空表）。
- **P5 团队总览**：筛选栏 + 总览 `Table`（风险列 ⚠ 可展开）+ 底部 AI 汇总区（四段 `Typography` + 复制/导出按钮）；未生成时汇总区显示引导文案。
